## Spacing Scale

Phase 6 D-03에서 DESIGN.md spacing 토큰 → Qt setSpacing / setContentsMargins 매핑 확정. 이 다이얼로그에 동일하게 적용.

| Token | Value | Qt Mapping | Usage |
|-------|-------|------------|-------|
| xxs | 4px | setSpacing(4) | 라벨-값 밀착 그룹 내 간격 |
| xs | 8px | setSpacing(8) | 행 간격 (필드 rows), 버튼 행 간격 |
| sm | 12px | setSpacing(12) | QVBoxLayout 루트 스페이싱 (fw_git_dialog 패턴 준수) |
| md | 16px | setContentsMargins(16,16,16,16) | 다이얼로그 외곽 여백 |
| lg | 24px | 섹션 간 (필요 시) | 탭 콘텐츠 섹션 간 구분 |

Exceptions:
- `fw_git_dialog.py` 기존 패턴이 `root.setSpacing(8)`, `setContentsMargins(12,12,12,12)` 사용 — WIZ550 FW 다이얼로그는 이 기존 패턴과 일관성을 위해 `setSpacing(8)` / `setContentsMargins(12,12,12,12)` 채택 (sm=12px 예외 허용)
- 탭 내 필드 행(QHBoxLayout): `setSpacing(8)` 고정
- 버튼 행 addStretch() → 오른쪽 정렬 (fw_git_dialog 동일 패턴)

## Typography

PyQt5 데스크톱 앱에서 웹 폰트(Copernicus, StyreneB) 사용 불가. 시스템 폰트로 매핑.
Phase 6 D-03 패턴 + 기존 main_gui.py/fw_git_dialog.py 패턴 준수.

| Role | Size | Weight | Line Height | Qt 구현 |
|------|------|--------|-------------|---------|
| Body | 13px | 400 (normal) | 1.4 | 기본 QLabel (setStyleSheet 없음) |
| Label | 13px | 400 (normal) | 1.4 | QLabel 고정폭 설정 (setFixedWidth) |
| Status message | 12px | 400 (normal) | 1.4 | QLabel "color: gray; font-size: 12px;" (기존 패턴) |
| Window title | 시스템 기본 | 500 (medium) | — | setWindowTitle() — OS 타이틀바 렌더링 |

> 총 3개 역할, 2개 weight (400/500). DESIGN.md의 body-sm(14px)보다 12-13px 소형으로 맞춤 — 기존 fw_git_dialog 13px 기준 준수.

## Color

Phase 6 D-05에서 DESIGN.md 컬러 토큰 → Qt 스타일시트 매핑 확정. 이 다이얼로그에 동일 적용.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | 시스템 기본 (#f0f0f0 / OS palette) | 다이얼로그 배경, 탭 배경 |
| Secondary (30%) | #faf9f5 (colors.canvas) | 입력 필드 배경 (text-input 패턴), QGroupBox 내 영역 |
| Accent (10%) | #cc785c (colors.primary) | Upload 버튼 배경만 (기존 Phase 6 Apply 버튼과 동일) |
| Success | #5db872 (colors.success) | 상태 메시지 "Upload complete!" 텍스트 색상 |
| Error | #c64545 (colors.error) | 오류 메시지 텍스트 색상 (port 69 실패, 타임아웃) |
| Muted | #6c6a64 (colors.muted) | 보조 설명 텍스트 ("Optional" 힌트 등) |

Accent reserved for: Upload 버튼 배경 한 군데만. Browse 버튼, Cancel 버튼, Refresh 버튼은 시스템 기본 버튼 스타일 유지.

> 기존 UI 전체 색상 교체 금지 — Phase 6 D-05 원칙 준수. WIZ550 FW 다이얼로그 내 신규 위젯에만 토큰 적용.

| Disabled | background-color: #e6dfd8; color: #6c6a64; border-radius: 6px | 업로드 진행 중 |
| Hover | background-color: #a9583e (primary-active) | QSS :hover |

# Upload 버튼 스타일 (primary)
btn_upload.setStyleSheet("""

### QProgressBar (D-07)

| State | Range | Value | 설명 |
|-------|-------|-------|------|
| 숨김 (초기) | (0, 100) | 0 | visible=False |
| Indeterminate (업로드 중) | (0, 0) | 0 | 애니메이션 시작, visible=True |
| 완료 | (0, 100) | 100 | 100% 점프 |

```python
# 업로드 시작
pgbar.setRange(0, 0)   # indeterminate
pgbar.setValue(0)
pgbar.setVisible(True)

# 완료 시
pgbar.setRange(0, 100)
pgbar.setValue(100)
```

### lbl_status 상태 메시지

| State | Text | Color |
|-------|------|-------|
| Idle | "" (공백) | — |
| 진행 중 | "Sending 0xD1 packet..." | 시스템 기본 |
| 완료 성공 | "Upload complete!" | #5db872 (success) |
| 오류 | [오류 메시지] | #c64545 (error) |

```python
lbl_status.setStyleSheet("color: #5db872;")  # 성공

```

### 입력 유효성 검증

| 필드 | 조건 | 오류 처리 |
|------|------|-----------|
| Server IP (수동 탭) | 4옥텟 0~255, socket.inet_aton() 통과 | lbl_status에 오류 색상 메시지 표시 |
| Port (수동 탭) | 1~65535 정수 | lbl_status에 오류 색상 메시지 표시 |
| File Name (수동 탭) | 비어있지 않음, 50자 이하 | lbl_status에 오류 색상 메시지 표시 |
| FW File (자동 탭) | 파일 선택됨, BOOT 파일 아님 | QMessageBox.warning 팝업 |

### Destructive Actions

이 다이얼로그에 파괴적 동작 없음. Upload는 장치 펌웨어를 덮어쓰지만 사용자가 명시적으로 파일을 선택하고 Upload를 눌러야 하므로 별도 확인 다이얼로그 불필요 (기존 firmware_update() 흐름과 동일).

단, 업로드 진행 중 Cancel 누를 경우:
- 서버 stop(now=True) + QThread 정리 후 다이얼로그 닫기
- 별도 확인 없이 즉시 중단 (진행 중 취소는 사용자 의지로 간주)
