# Plan 02-01: Module Metadata

## Goal

`specs/commands/*.yaml` 11개 파일 각각에 `meta:` 블록을 추가한다. 각 블록은 Phase 1에서 정의한 `command-group.schema.json`을 통과해야 하며, requires/conflicts 필드는 실제 장치 조합을 반영해야 한다.

## Context

Phase 1에서 정의한 `meta:` 스키마 필드:
- `id` (string): 파일명과 동일한 모듈 식별자
- `name` (string): 사람이 읽는 모듈명
- `category` (string): 에디터 그룹핑용 카테고리
- `description` (string): 모듈 목적 한 줄 설명
- `requires` (array of string): 이 모듈이 의존하는 다른 모듈 ID 목록
- `conflicts` (array of string): 같이 쓸 수 없는 모듈 ID 목록

## YAML 삽입 형식

```yaml
meta:
  id: <id>
  name: "<사람이 읽는 이름>"
  category: <category>
  description: "<한 줄 설명>"
  requires:
    - <module_id>   # 없으면 빈 배열 []
  conflicts:
    - <module_id>   # 없으면 빈 배열 []

# 기존 커맨드 정의들...
```

## Acceptance Criteria

1. `specs/commands/` 하위 11개 YAML 파일 모두 meta: 블록 보유
