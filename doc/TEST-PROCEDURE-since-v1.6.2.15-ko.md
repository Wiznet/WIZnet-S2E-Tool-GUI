# v1.6.2.15 이후 변경 사항 — 변경 목록과 시험 절차서 (exe 시험용)

> 대상: v1.6.2.15(2026-08-28 릴리즈) 이후 `develop` 에만 있는 변경.
> 용도: 개발 환경이 없는 동료가 **전달받은 exe 와 장치만으로** 시험하고 결과를 기록한다.
> 터미널 명령, Python, `uv` 는 쓰지 않는다. 자동 시험(pytest)과 가짜 장치는 개발자 몫이며 `doc/dev/TESTING-ko.md` 에 있다.
> 변경 내역의 영문 정본은 `CHANGELOG.md` 의 `[Unreleased]` 항목이다.

## 0. 시험 전에

### 0-1. 준비물

| 항목 | 내용 |
| --- | --- |
| 프로그램 | 담당자가 전달한 `wizconfig_s2e_tool_<버전>.exe` (설치 없음, 더블클릭) |
| PC | Windows, 장치와 **같은 네트워크(서브넷)** 에 연결 |
| 장치 | 가진 것만. 없는 항목은 "미시험" |

### 0-2. 시험 대상 확인 (먼저 적는다)

| 항목 | 방법 | 기록 |
| --- | --- | --- |
| exe 파일명 | 받은 파일 이름 | |
| 버전 | Help → About ... | |
| 시험자 / 일시 | | |

> 담당자가 알려 준 시험용 버전과 About 의 버전이 다르면 시험을 시작하지 않는다.

### 0-3. 시험 전에 해 둘 것

- **장치 설정을 백업**한다: 장치를 선택한 상태에서 화면을 캡처하거나 목록을 CSV 로 저장한다.
- 시험 중 바꾼 값은 항목이 끝나면 **원래대로 되돌린다** (특히 IP, 비밀번호, Baud).
- 펌웨어 업로드는 **하지 않는다.** 복구 수단이 없으면 장치가 못 쓰게 될 수 있다.

### 0-4. 결과 기록

각 시험의 `결과` 칸에 **PASS / FAIL / 미시험** 중 하나를 적는다. FAIL 이면:

1. 화면을 캡처한다 (오류 팝업 문구는 그대로 옮겨 적는다).
2. 로그 파일을 담당자에게 보낸다: `%USERPROFILE%\.wizconfig\logs\wizconfig.log`
   (탐색기 주소창에 그대로 붙여 넣으면 폴더가 열린다).
3. 무엇을 눌렀는지 순서대로 적는다.

### L1. W55RP20-S2E-4CH (4CH 가 있을 때) — 위험 높음

동료가 며칠 써 보고 이상 없다고 한 이력이 있다. 그래도 아래를 명시적으로 확인한다.

**L1-a. 화면 구성**

| 단계 | 기대 |
| --- | --- |
| 1. Search → 4CH 선택 | Channel #0 ~ #3 탭이 모두 보인다 |
| 2. 각 채널 **Flow control** 목록 | **DTR/DSR** 이 선택지에 있다 |
| 3. **Serial interface** | 읽기 전용이 아니라 TTL / RS-232 / RS-422 / RS-485 / RS-485 Reverse 를 고를 수 있다 |
| 4. 각 채널 Remote host 에 도메인(`test.example.com`) 입력 | 입력이 거부되지 않는다 |

**L1-b. Apply 가 저장되는지** (예전에는 성공 메시지 없이 저장 안 됨)

| 단계 | 기대 |
| --- | --- |
| 1. 채널0 Baud 와 채널1 Baud 를 바꾼다 | |
| 2. F4 | 완료 팝업이 뜬다 |
| 3. Search 후 장치 선택 | 변경한 값이 그대로 남아 있다 |
| 4. 장치 전원을 껐다 켠 뒤 다시 확인 | 값이 유지된다 |
| 5. 원래대로 되돌린다 | |

**L1-c. 값 범위** — 범위 밖 값은 F4 전에 입력 오류로 막혀야 한다.

| 필드 | 허용 범위 |
| --- | --- |
| OP / AO / TO / JO | 0~3 |
| Flow control | 0~5 |
| Keep-alive · 재접속 · 비활성 시간 | 최소 1000 ms |

**L1-d. 다른 W55RP20 계열 회귀** — 1CH / 2CH(W55RP20-S2E) 가 있으면 L0 에 더해 Channel 탭의 값 변경·F4·재검색을 한 번 더 한다.

## 2. 알려진 한계 — 결함으로 보고하지 않는다

- **3CH** 는 준비 단계다. 시험 대상이 아니다.
- 호환표 **원격 갱신**은 아직 동작하지 않는다 (GitHub 에 파일이 올라간 뒤에 동작).
- FW from Git 에는 3CH/4CH 용 공개 이미지가 없다. 4CH 장치에서 "지원하지 않음" 안내가 나오는 것이 정상이다.
- 프리셋 값이 Advanced 설정과 어긋나는 문제는 아직 고치지 않았다.
- 장치가 응답 일부만 돌려주는 경우를 "Device rebooted" 로 안내하는 동작은 이대로 둔다.
- IP20 Windows 11 종료 문제의 근본 원인은 확정되지 않았다.
