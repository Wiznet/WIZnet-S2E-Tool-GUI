# WIZnet S2E Configuration Tool — 제품별 시험 시나리오 (exe 시험용)

> 대상 빌드: `1.6.2.24-dev6` 이후. 시험 대상 exe 는 담당자가 전달한 `wizconfig_s2e_tool_<버전>.exe`.
> 용도: **제품 담당자가 자기 제품을 exe 와 실장비만으로** 시험하고 결과를 기록한다. Python·`uv`·터미널 명령은 쓰지 않는다.
> 구성: **0 공통 안내 → 1 제품·공통 시험 매트릭스 → 2 공통 시험(C) → 3 제품별 시험(P1~P11) → 4 알려진 한계 → 5 결과 요약**
> 이 문서와 `TEST-PROCEDURE-since-v1.6.2.15-ko.md` 의 관계: 그 문서는 **최근 변경분**(R/L 항목)의 확인표이고, 이 문서는 **제품 기능 전체**의 시험표다. 겹치는 항목은 ID 로 서로 가리킨다(`R7`, `L1` 등).
> 기대 결과는 코드·제품 사양(spec) 파일을 근거로 썼다. **실장비에서 한 번도 실행해 확인한 표가 아니다.** 기대와 다르면 바로 FAIL 로 적고, 기대가 틀린 것일 수도 있으니 증빙을 함께 보낸다.

## 0. 공통 안내 (모든 제품, 모든 시험 전에)

### 0-1. 준비물

| 항목 | 내용 |
| --- | --- |
| 프로그램 | `wizconfig_s2e_tool_<버전>.exe` (설치 없음, 더블클릭) |
| PC | Windows 10/11. 장치와 **같은 서브넷**의 유선 NIC. Wi-Fi·VPN·가상 NIC 가 있으면 검색 NIC 선택을 꼭 확인한다 |
| 장치 | 시험할 제품 1대 이상. **여러 대가 있는 제품은 1대만으로 먼저 시험하고, 다장치 시험은 C12 에서 한다** |
| 기록 | 이 문서를 복사해 각 표의 `결과` 칸에 적는다 |

### 0-2. 시험 대상 확인 (제일 먼저 적는다)

| 항목 | 기록 |
| --- | --- |
| exe 파일명 | |
| 버전 (Help → About) | |
| 시험자 / 일시 | |
| 제품 / 장치 FW 버전 / 개수 | |
| PC OS / NIC (유선 NIC 이름) | |

> About 의 버전이 담당자가 알려 준 시험용 버전과 다르면 시험을 시작하지 않는다.

### 0-3. 안전 수칙

1. **시험 전에 설정을 백업한다.** 장치를 선택한 상태에서 화면을 캡처하고, Search 후 목록을 CSV 로 저장한다(C7).
2. **바꾼 값은 항목이 끝날 때마다 원래대로 되돌린다.** 특히 IP, 접속 비밀번호, 검색 ID 코드, Baud, IM(IP 할당 방식).
3. **펌웨어 업로드(Firmware Upload 의 실제 전송)와 `Factory default firmware` 는 하지 않는다.** 복구 수단이 없으면 장치가 못 쓰게 될 수 있다. FW from Git 은 **목록과 경고 문구만 본다.**
4. **IM 을 PPPoE 로 바꾸거나 IP 를 바꾸는 시험은 접속이 끊길 수 있다.** 원복 방법(시리얼 콘솔·물리 리셋)이 있을 때만 한다. 표에 ⚠ 가 붙은 항목이다.
5. **Factory Reset(설정 초기화)은 백업 후**에만 한다(C8).
6. 장치가 응답하지 않으면 전원을 껐다 켜고 C2 부터 다시 한다. 그 사실을 비고에 적는다.

### 0-4. 결과 기록 방법

각 시험 행의 `결과` 칸에 아래 중 하나를 적는다.

| 기호 | 뜻 |
| --- | --- |
| **P** | PASS — 기대대로 |
| **F** | FAIL — 기대와 다름 (증빙 필수) |
| **N** | 미시험 — 장치·환경이 없어서 안 함 |
| **B** | 차단 — 앞 단계 실패로 진행 불가 |
| **K** | 알려진 한계에 해당 (§4 항목 번호를 비고에 적는다) |

**F 로 적을 때 보낼 것** (이 세 가지가 있으면 재현이 거의 끝난다):

1. 화면 캡처 (오류 팝업 문구는 그대로 옮겨 적는다)
2. 로그: `%USERPROFILE%\.wizconfig\logs\wizconfig.log` (탐색기 주소창에 붙여 넣으면 폴더가 열린다). 가능하면 **Option → Log Level → DEBUG** 로 올린 뒤 증상을 다시 만들고 보낸다
3. 누른 순서, 장치 FW 버전, 장치 개수

### 0-5. 시험 순서

**C1 → C2 → C3 → C4 → C5 → (해당 제품 P 절) → C6~C11 → C12(여러 대일 때) → 원복 확인**
제품 고유 시험(P 절)은 공통 C2~C5 가 끝난 뒤에 한다. 공통에서 F 가 나오면 그 제품의 나머지는 B 로 적고 보고한다.

## 2. 공통 시험 (C)

> 아래 "장치"는 시험 중인 제품의 장치 1대다. 제품마다 화면의 탭 이름·항목이 다르므로 **구성은 제품 절(P)에서 확인한다.**

### C1. 기동 · About · 메뉴

| ID | 단계 | 기대 | 결과 | 비고 |
| --- | --- | --- | --- | --- |
| C1-1 | exe 를 더블클릭 | 창이 열린다. 제목줄에 `WIZnet S2E Configuration Tool V<버전>` | | |
| C1-2 | Help → About | 버전이 0-2 에 적은 것과 같다. `(BETA - 4CH)` 표기가 없다 | | |
| C1-3 | File / Option / Help 메뉴를 하나씩 연다 | 메뉴가 열리고 오류 팝업이 없다. Option 에 **Network Interface Config**(서브메뉴), **Log Level**, **FW Download Path…**, **Advanced Search Options…** 가 있다. 검색 NIC 는 메뉴 또는 **왼쪽 위 콤보**(`<Select Network Interface>`)로 고른다 | | |
| C1-4 | 창 크기를 줄였다 키운다 | 글자가 겹치거나 잘리지 않는다 | | |
| C1-5 | Exit | 정상 종료. 작업 관리자에 프로세스가 남지 않는다 | | |

### C2. 브로드캐스트 검색

| ID | 단계 | 기대 | 결과 | 비고 |
| --- | --- | --- | --- | --- |

| C2-8 | **Search ID code** 가 설정된 장치(있을 때): 칸에 코드 입력 후 Search / 비워 두고 Search | 맞는 코드면 나온다. 코드가 없거나 틀리면 해당 장치가 나오지 않는다 | | |

### C4. 설정 변경 · Apply 왕복 (F4)

제품에 없는 항목은 건너뛰고 비고에 `해당 없음`.

| C4-14 | 경계값 — 포트 | `0`, `65535`, `65536`, 빈칸, 문자 | `0~65535` 만 통과. 나머지는 F4 전에 막히거나 오류 | | |
| C4-15 | 경계값 — IP 형식 | `999.1.1.1`, `1.2.3`, 빈칸 | 형식 오류로 막힌다 | | |
| C4-16 | 변경 없이 F4 | 아무것도 안 바꿈 | 오류 없이 완료 | | |
